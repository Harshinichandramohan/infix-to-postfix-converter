00 • TOPIC INTRODUCTION

What is Infix to Postfix Conversion?

An infix expression places operators between operands, such as A + B. A postfix expression places the operator after its operands, such as AB+. Postfix notation does not need parentheses to show the order of operations, so it is convenient for computers to evaluate using a stack.

In this project, a stack is used to temporarily store operators and parentheses while the expression is scanned from left to right. Operands are added directly to the postfix expression, while operators are pushed or popped according to their precedence.

Infix: A + B   →   Postfix: AB+   →   Stack: manages operators
00.1 • CONVERSION RULES

Rules for Infix → Postfix Conversion

The conversion is done from left to right. Each rule is shown separately for easy reading.

Scan left to right

Read the expression one operand, operator, or bracket at a time.

Operand

A letter or complete number goes directly to the postfix output.

Opening parenthesis

Push ( into the stack.

Closing parenthesis

Pop operators until ( is found, then remove the (.

Operator

Check the current operator against the operator at the top of the stack.

Higher precedence

If the current operator has higher precedence, push it onto the stack.

Lower or equal precedence

Pop higher or equal precedence operators to the output, then push the current operator.

End of expression

After all input is processed, pop every remaining operator from the stack.

Final postfix

The output after all stack operations is the final postfix expression.

^ → Highest    * / % → Medium    + - → Lowest
Operand → Output   |   ( → Push   |   ) → Pop   |   Operator → Check precedence   |   End → Pop all

PSEUDOCODE

Algorithm used

This is the logic implemented by the C program.

BEGIN Read infix expression Initialize empty stack Scan left to right IF operand Add to postfix ELSE IF '(' Push into stack ELSE IF ')' Pop until '(' ELSE IF operator Pop higher/equal precedence Push current operator Pop remaining operators Display postfix expression END

How the stack helps: The stack temporarily stores operators and parentheses. It prevents an operator from being placed in the output too early. When a new operator is read, precedence decides whether the old operator should leave the stack first.

Precedence: ^ → * / % → + -. The project uses an array-based stack, matching the core C implementation.

C PROGRAM

C Implementation

The following C program uses an array-based stack to convert an infix expression into postfix notation.

#include <stdio.h> #include <ctype.h> #define MAX 100 char stack[MAX]; int top = -1; void push(char value) { stack[++top] = value; } char pop() { return stack[top--]; } char peek() { return stack[top]; } int isEmpty() { return top == -1; } int precedence(char operator) { if (operator == '^') return 3; if (operator == '*' || operator == '/' || operator == '%') return 2; if (operator == '+' || operator == '-') return 1; return 0; } int isOperator(char character) { return character == '+' || character == '-' || character == '*' || character == '/' || character == '%' || character == '^'; } void infixToPostfix(char infix[], char postfix[]) { int i = 0; int j = 0; char character; while (infix[i] != '\0') { character = infix[i]; if (isalnum(character)) { postfix[j++] = character; } else if (character == '(') { push(character); } else if (character == ')') { while (!isEmpty() && peek() != '(') { postfix[j++] = pop(); } if (!isEmpty() && peek() == '(') { pop(); } } else if (isOperator(character)) { while (!isEmpty() && peek() != '(' && precedence(peek()) >= precedence(character)) { postfix[j++] = pop(); } push(character); } i++; } while (!isEmpty()) { postfix[j++] = pop(); } postfix[j] = '\0'; } int main() { char infix[MAX]; char postfix[MAX]; printf("=====================================\n"); printf(" INFIX TO POSTFIX CONVERTER\n"); printf("=====================================\n\n"); printf("Enter an infix expression: "); scanf("%99s", infix); infixToPostfix(infix, postfix); printf("\nInfix Expression : %s", infix); printf("\nPostfix Expression: %s\n", postfix); return 0; }
